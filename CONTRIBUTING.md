# Contributing Guide

## How to Contribute

We welcome contributions! Please follow these guidelines:

### Before You Start

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/OnePageResume.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Install dependencies: `npm install`

### Making Changes

1. Make your changes in the new branch
2. Follow the code standards in [DEVELOPMENT.md](DEVELOPMENT.md)
3. Test your changes: `npm test`
4. Lint your code: `npm run lint`

### Committing

- Use descriptive commit messages
- Use conventional commits format (see DEVELOPMENT.md)
- Keep commits focused and logical

### Pushing & Creating a Pull Request

1. Push your changes: `git push origin feature/your-feature-name`
2. Go to GitHub and create a Pull Request
3. Provide a clear description of your changes
4. Link any related issues

### PR Review Process

- Code will be reviewed for quality and consistency
- Tests must pass
- Code must follow the style guidelines
- At least one approval required before merge

## Types of Contributions

- **Bug fixes**: Fix issues in the code
- **Features**: Add new functionality
- **Documentation**: Improve README, guides, etc.
- **Performance**: Optimize code and bundle size
- **Accessibility**: Improve a11y features
- **Tests**: Add or improve test coverage

## Code of Conduct

- Be respectful and inclusive
- Provide constructive feedback
- Help others learn and grow
- Report inappropriate behavior

## Questions?

Feel free to:
- Open an issue for discussions
- Check existing documentation
- Ask in pull request comments

Thank you for contributing! 🙏
